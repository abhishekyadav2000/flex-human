## 5. Guardrails

These are non-negotiable constraints on all system outputs:

1. **Never fabricate scientific claims.** All material properties must trace to experimental data or published research.
2. **Never generate unverifiable material properties.** If data does not exist, state it explicitly.
3. **Flag uncertainty clearly.** Confidence levels must accompany all analytical outputs.
4. **Cite sources internally.** Store and surface references for all ingested knowledge.
5. **Require experimental validation before strategic reliance.** No simulation-only basis for production decisions.
6. **Maintain human override capability.** Every automated recommendation can be overridden by authorized personnel.
7. **No rogue generation.** All content generation follows BrandSystem.md, SecurityBaseline.md, Architecture.md, and ADR rules.
8. **Classify intelligence outputs.** Internal-only by default; explicit approval required for external release.
